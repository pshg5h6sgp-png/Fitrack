FITTRACK iPhone Web App

Files: index.html, style.css, app.js

To use on iPhone:
1. The files need to be hosted on a web page. If you have a computer, upload these 3 files to a static host.
2. Open the resulting HTTPS page in Safari.
3. Tap Share -> Add to Home Screen.
4. FitTrack will then open like an app and save your profile/workouts in Safari on that device.

The app includes profile, exercise list, conservative starting-load estimates, workout logging, and history/progress.
